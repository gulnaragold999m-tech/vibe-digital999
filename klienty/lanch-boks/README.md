# Лендинг кафе «Ланч Бокс» — Лермонтов

Кофе на вынос, шаурма, картофель фри. Одностраничный сайт: меню,
конфигуратор стакана, заказ в Telegram или WhatsApp готовым текстом,
маршрут до точки.

Сделан 19.08.2026 по брифу заказчицы. **Сейчас это черновик:** цены,
телефон и адрес примерные, вверху страницы висит жёлтая полоса.

## Цены — настоящие, с досок

19.08.2026 владелица прислала фотографии двух меловых досок кафе. Все
23 цены перенесены в `dannye.js` слово в слово. Ничего не добавлено
«от себя»: сиропов, растительного молока и скидок на досках нет —
значит, нет и на сайте.

**Что нужно уточнить по меню:** два числа через дробь («шаурма 300/350»,
«эспрессо 80/100») — это два варианта позиции. Как они называются
у вас на кассе, я не знаю: сейчас стоят «обычная / большая» и объёмы
кофе по обычной практике. Поправить в `dannye.js`.

## Что заполнить перед публикацией

Всё в одном файле — `site/assets/js/dannye.js`. В разметке нет ни одной
цены и ни одного телефона намеренно: иначе они разъедутся между сайтом,
кассой и рекламой.

- [ ] `telefon` — телефон точки
- [ ] `telegram` — ссылка на бота или аккаунт для заказов
- [ ] `whatsapp` — номер для заказов
- [ ] `vk` — сообщество (пусто — кнопка сама исчезнет)
- [ ] `adres` и `marshrut` — точный адрес и ссылка на Яндекс Карты
- [ ] `chasy` — часы работы
- [x] `menu` — перенесено с досок 19.08.2026
- [ ] названия вариантов («обычная/большая», объёмы кофе) — уточнить
- [ ] `otzyvy` — реальные отзывы с Яндекс Карт. **Выдуманных не ставим.**
      Пока список пуст, секция отзывов не показывается.
- [ ] `chernovik: false` — последним действием, полоса исчезнет

Ещё нужны от заказчицы:

- [ ] Логотип в векторе. Сейчас на странице круглый знак, собранный
      стилями; настоящий логотип лежит в файле `.studio3` (Silhouette),
      из него нужен SVG или PNG на прозрачном фоне.
- [ ] Фотографии: шаурма в разрезе, фри крупно, точка снаружи.
      На первом экране сейчас стоит кадр стакана из файла наклейки —
      единственная настоящая картинка, которая у нас есть.
      **Сток с чужими правами не ставим.**
- [ ] Карта: сейчас на её месте заглушка. Встроим, когда подтвердится адрес.

## Как посмотреть

Локально: открыть `site/index.html` в браузере, всё работает без сервера.

Показать заказчице одной ссылкой: `node sobrat-prosmotr.mjs` — соберёт
`prosmotr.html`, в который вложены стили, скрипты и фото.

## Как устроено

```
site/index.html              разметка, без единой цены
site/assets/css/site.css     стили; все значения токенами в :root
site/assets/js/dannye.js     ЕДИНСТВЕННОЕ место, где живут данные
site/assets/js/site.js       меню, корзина, бот-помощник, Schema.org
site/assets/img/stakan.jpg   кадр из файла наклейки заказчицы
sobrat-prosmotr.mjs          однофайловый предпросмотр для показа
```

Стек — чистые HTML, CSS и JS: ни React, ни сборщика. Страница
открывается без сборки, грузится одним файлом стилей и двумя
маленькими скриптами.

## Чего ещё нет

- **Анимации.** Сделано намеренно: движение добавляется последним шагом,
  на готовую и принятую статику. План — появление заголовка и стакана
  при загрузке, мягкая смена вариантов в конфигураторе, история про
  зерно при прокрутке.
- **Хостинга.** В брифе указан Vercel. У студии рабочий опыт на Amvera,
  сайт студии с Vercel как раз переезжал. Решает заказчица; от выбора
  зависит только способ выкатки, код одинаковый.
- **Своего репозитория.** По правилу проекта организация = репозиторий,
  и у кафе он должен быть свой. Пока лежит здесь, в `klienty/`, — хвост
  записан в `TASKS.md`.

## Гео-SEO

Заголовок, описание и `alt` у фото содержат «Лермонтов» и «кофе с собой».
Разметка `Restaurant` собирается скриптом из тех же данных, что и
страница, — адрес и часы не могут разойтись с текстом.
