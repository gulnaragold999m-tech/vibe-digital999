## Как сайт попадает в интернет

Не автоматически. Push в GitHub на сайт НЕ выкатывает — Amvera про GitHub
не знает. Выкатка — это отдельный push в remote Amvera, который заведён у
Гульнары в её локальной папке.

Два шага, оба обязательны, порядок именно такой:

```
git fetch origin <ветка>
git push -f amvera origin/<ветка>:master
```

Почему сначала `fetch` и что бывает, если наоборот, — в `CLAUDE.md`, раздел
«Как выкатывается сайт». Это самая дорогая ловушка проекта, читать до того,
как давать команды.

**Имя remote — `amvera`**, адрес `https://git.amvera.ru/granatgold999/vibe-digital`.
Подтверждено 10.08.2026: этим подключением сайт выкатан на живой домен.

## Чего ещё НЕТ

**Выкатка с телефона.** В репозитории лежит запуск
`.github/workflows/deploy-amvera.yml`. Открыть GitHub → вкладка Actions →
«Выкатить сайт на Amvera» → Run workflow → выбрать ветку. Компьютер
не нужен. Запускается только руками: на push намеренно не повешено,
чтобы случайный коммит не уехал на живой сайт.

Работает после того, как в Settings → Secrets and variables → Actions
заведены `AMVERA_USERNAME` и `AMVERA_PASSWORD`. **Логин от Amvera,
а не от GitHub** — на этом уже падали дважды в соседнем проекте.

**Как проверять бота ВК.** Написать ему **со своей личной страницы**,
а не из чата сообщества. Сообщение, отправленное от имени сообщества,
бот пропускает намеренно — у таких сообщений отрицательный `from_id`,
и отвечать на них значит разговаривать с самим собой и зациклиться.
12.08.2026 бота так проверяли, и молчание приняли за поломку. Теперь
он пишет в лог, почему промолчал.

**Как НЕ проверять, работает ли бот.** В логе локального запуска строки
`[vk-bot] Не настроен (нет VK_TOKEN…)` и `[tg-bot] Не настроен…`
печатаются просто потому, что в песочнице ассистента нет `.env`.
Про боевые настройки на Amvera они не говорят ничего. 12.08.2026 чат
на этом основании сообщил Гульнаре, что бот ВК выключен, — а она в это
время с ним переписывалась. Проверять только у неё: написать боту
и посмотреть, отвечает ли.
