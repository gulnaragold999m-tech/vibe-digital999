## В работе

### Привязать домен vibe-digital999.ru

DNS-записи у reg.ru прописаны верно:

| Тип | Хост | Значение |
|-----|------|----------|
| A | @ | 158.160.116.199 |
| A | www | 158.160.116.199 |
| TXT | @ | granatgold999-vibe-digital |

Осталось дождаться обновления кэша DNS и нажать в Amvera
«Создать доменное имя» → «Свой домен». Проверка записей:

```bash
curl -s "https://dns.google/resolve?name=vibe-digital999.ru&type=TXT" | grep -o '"data":"[^"]*"'
```

## Очередь

Порядок работ по гео-продвижению и узнаваемости, разложенный по неделям, —
в `docs/13-GEO-SEO-PLAN.md`. Пункты ниже в него встроены.

### 1. Цели в Яндекс.Метрике

Счётчик стоит и собирает визиты, но цели надо создать руками:
Метрика → Настройки → Цели → Добавить → тип **JavaScript-событие**.

| Идентификатор | Когда срабатывает |
|---------------|-------------------|
| `lead_sent` | заявка успешно отправлена |
| `click_tel` | клик по телефону |
| `click_wa` | клик по WhatsApp |
| `click_tg` | клик по Telegram |
| `click_vk` | клик по ВКонтакте |
| `click_order` | клик по кнопке «Заказать» |
| `quiz_start` | открыл квиз |
| `quiz_done` | дошёл до результата квиза |
| `speed_test` | нажал «Замерить» |
| `open_chat_max` | открыл чат |

Без `lead_sent` и `click_wa` Директ не сможет работать по оплате за конверсии.

Там же поменять адрес счётчика со старого `my-vibecoding-agenci.vercel.app`
на `vibe-digital999.ru`.

### 2. Скриншоты работ в портфолио

Сейчас карточки текстовые. Нужно по каждому проекту:
ссылка на живой сайт, один-два скриншота, город клиента,
одна строка результата. Файлы класть в `public/assets/`.

Проекты: сайт Гранат, автошкола «Старт» (сайт и приложение),
Telegram-боты, этот сайт.

Отдельно уточнить, что умеет приложение для автошколы —
сейчас про него в карточке ни слова, а это самая сильная позиция.

### 3. ОГРНИП в подвал

На сайте granat-kmv.ru его нет, только ИНН. Для B2B полезен:
корпоративный клиент проверяет подрядчика перед оплатой.

### 4. Тест-драйв скорости, вариант Б — через Telegram

Идея: кнопка открывает `t.me/vibedigital999_bot?start=speedtest`,
человек нажимает Start, бот мгновенно отвечает с замером времени.

**Почему не сделали сразу:** бот не может написать первым тому, кто
не начинал с ним диалог. По номеру телефона или по нику Telegram
отправлять запрещает. Единственный рабочий путь — deep-link,
где человек сам нажимает Start.

**Что нужно:** бот сейчас умеет только отправлять. Для этого варианта
нужен обработчик входящих команд — отдельный сервис на Node.js
с вебхуком. Оценка: день-полтора.

**Когда делать:** после запуска рекламы, когда пойдёт трафик.
До первых посетителей тратить полтора дня рано.

### 5. QR-код для оплаты

Есть файл `IP Melkonyan GR - статический TQR-код.PDF`.

На лендинг ставить не стоит: услуги от 15 000 ₽ и «по брифу»,
цена считается под задачу. Публичный QR предлагает заплатить
непонятно сколько до разговора и сметы.

Варианты: отправлять в переписке после согласования сметы,
либо отдельной страницей `/oplata` без ссылок из меню.

Решение за владельцем.
