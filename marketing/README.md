# Макеты и карточки

Здесь три генератора. Всё, что они рисуют, лежит готовым в `out/` —
чтобы этим можно было пользоваться, ничего не устанавливая.

| Что | Команда | Нужен playwright |
|---|---|---|
| Рекламные макеты для ВК и 2ГИС | `node marketing/creatives.js` | да |
| Карточки пакетов для Яндекс Карт | `npm run karty-kartinki` | да |
| Текст прайса для Яндекс Карт | `npm run karty` | нет |

Цены и сроки во всех трёх берутся из `src/prices.js`. Руками их здесь
не вписывать — разъедутся, это уже случалось трижды.

## Рекламные макеты — `creatives.js`

| Файл | Услуга | Цена на макете |
|---|---|---|
| `out/lending.png` | Сайт-лендинг | от 35 000 ₽ |
| `out/bot.png` | Бот для заявок | от 15 000 ₽ |
| `out/agent.png` | ИИ-агент для бизнеса | от 60 000 ₽ |
| `out/audit.png` | SEO-аудит и 152-ФЗ | 15 000 ₽ |

Размер 1080×1350 — самый высокий формат, который лента ВК показывает
целиком, не обрезая.

## Карточки пакетов — `karty-cards.js`

| Файл | Пакет |
|---|---|
| `out/paket-start.png` | «Старт» |
| `out/paket-potok.png` | «Поток» |
| `out/paket-sistema.png` | «Система» |

Квадрат 1080×1080: показывается целиком и в карточке Яндекс Карт,
и в ленте ВК. Название, состав, кому подходит и срок читаются
из `src/prices.js` — в файле генератора их нет вовсе.

**Цены на карточке намеренно нет.** Во-первых, у Яндекса цена — отдельное
поле рядом с картинкой, и цифра на изображении её дублирует: поле
поправят, картинку забудут. Во-вторых, модерация снимает изображения
с рекламными наложениями, а где проходит граница между составом пакета
и рекламной фразой — по документации не понять. Поэтому карточка
сдержанная: что входит, кому, срок. Ни цены, ни призыва.

## Как поправить текст или цену

Цену и срок — только в `src/prices.js`, потом перерисовать. Текст
рекламных макетов лежит в начале `creatives.js`, в списке `ITEMS`.
Поправили — пересобрали:

```bash
node marketing/creatives.js
```

Одна услуга отдельно:

```bash
node marketing/creatives.js audit
```

Первый запуск попросит поставить playwright — им рисуются картинки:

```bash
npm install --no-save playwright
```

**Почему его нет в `package.json`.** Amvera ставит зависимости при каждой
сборке сайта, а playwright тянет за собой браузер на сотни мегабайт. Сайту
он не нужен — нужен только здесь и только когда перерисовываешь макеты.

## Правила, которые нельзя нарушать

**Верхние 540 пикселей — зона превью.** В ленте ВК и в галерее 2ГИС
картинку сначала показывают маленькой, и видно только их. Название услуги,
цена и срок обязаны помещаться туда. Скрипт печатает при сборке, на какой
высоте заканчивается цена, — если больше 540, текст надо укорачивать.

**Один знак.** Никаких чужих логотипов. Внизу набором стоит
«VIBE DIGITAL 999» — тем же Cinzel, что на сайте. Когда появится
собственная пиктограмма, она встанет туда же, и только туда.

**Цена обязательна.** Она отсекает тех, у кого бюджет три тысячи, ещё до
клика — в рекламе с оплатой за клики это прямая экономия.

**Одно действие.** Внизу «Оставить заявку» и адрес сайта. Второй кнопки
на макете быть не должно.

**Язык клиента, а не разработчика.** Не «Node.js», «Архитектура» и
«60 FPS», а «Исходники передаём вам», «Договор и ИП», «Заявка приходит
в Telegram». Владелец автошколы не выбирает подрядчика по стеку.

**Разный цвет у каждой услуги.** Циан, синий, фиолетовый, розовый. Четыре
одинаковых картинки в ленте читаются как одна повторённая.

**Картинка в центре показывает результат**, а не абстракцию: сайт, заявки
в Telegram, разговор агента, отчёт аудита. Абстрактная композиция не
объясняет, что покупают.

## Про шрифты

Код вшивания лежит отдельным файлом `shrifty.js`: им пользуются оба
генератора картинок, а копия кода в двух файлах и есть тот второй
источник правды, из-за которого в проекте разъезжались цены.

Файлы шрифтов вшиваются в разметку из `public/assets/fonts` — те же самые,
что отдаёт сайт. Поэтому буквы в рекламе и на сайте совпадают до пикселя,
и генератор работает, даже если сайт не запущен.

Объявления `@font-face` берутся из `fonts.css` целиком, вместе с
`unicode-range`. Это не мелочь: без него побеждает последнее подходящее
объявление, кириллица уезжает в латинский файл, где её нет, и заголовок
молча набирается системным шрифтом. На глаз ловится не сразу, а буквы уже
не те, что на сайте.
