# Pixel Runner 999 — платформер на Unity

Игра в духе классических платформеров: бежим вправо, прыгаем по блокам,
топчем врагов, собираем монеты, добираемся до флага. Три уровня.

Собрана как витрина студии: показывать заказчикам, что мы делаем не только
сайты. Название своё, не чужое — чтобы не брать чужой товарный знак.

---

## Как запустить у себя — по шагам

Пока Unity на компьютере нет, поэтому первый шаг длинный. Дальше проще.

### Шаг 1. Поставить Unity Hub

**В браузере** откройте `https://unity.com/download`, скачайте **Unity Hub**
и установите. Это не сама Unity, а её «менеджер»: через него ставятся версии.

**Что увидим:** окно Unity Hub с разделами Projects, Installs, Learn.

### Шаг 2. Поставить саму Unity

**В Unity Hub** слева нажмите **Installs** → **Install Editor** → выберите
любую версию с пометкой **LTS** (например 2022.3 или 6000.0) → **Install**.

Дополнительных модулей отмечать не надо: игра работает на голом редакторе.

**Что увидим:** полоску загрузки. Занимает 10–30 минут — качается 4–8 ГБ.

### Шаг 3. Создать пустой проект

**В Unity Hub** → **Projects** → **New project** → шаблон **2D** →
имя `PixelRunner999` → **Create project**.

**Что увидим:** откроется редактор Unity, серое окно с пустой сценой.
Первый запуск думает пару минут, это нормально.

### Шаг 4. Положить игру в проект

**В проводнике Windows** скопируйте из этого репозитория папку

```
igry\pixel-runner-999\Assets\PixelRunner
```

внутрь папки `Assets` вашего нового проекта. Путь получится такой:

```
C:\...\PixelRunner999\Assets\PixelRunner
```

**Что увидим:** Unity сама заметит новые файлы и на пару секунд покажет
полоску «Importing». В окне Project появится папка `PixelRunner`.

### Шаг 5. Играть

**В Unity** нажмите кнопку **▶ Play** — треугольник сверху по центру.

**Что увидим:** синее небо, надпись `PIXEL RUNNER 999` и «НАЖМИТЕ ПРОБЕЛ».

**Если вместо игры пусто** — посмотрите на нижнюю строку редактора: там будет
текст ошибки. Пришлите его мне, разберём.

## Управление

| Клавиши | Что делает |
|---|---|
| `←` `→` или `A` `D` | бежать |
| `ПРОБЕЛ` (или `↑`, `W`) | прыжок. Держите дольше — прыжок выше |
| `SHIFT` или `X` | ускорение: с разбега прыжок длиннее |
| `P` или `Esc` | пауза |
| `R` | начать заново |
| `M` | музыка вкл/выкл |

Прыжок на голову врагу его убивает. Черепаха прячется в панцирь, а панцирь
можно пнуть — он поедет и снесёт всех на пути, включая вас на обратном ходу.

Гриб из блока `?` делает героя большим: большой переживает одно попадание
и разбивает кирпичи головой.

## Как править уровни — без программирования

Уровни лежат обычными текстовыми файлами:

```
Assets\PixelRunner\Resources\urovni\uroven-1.txt
```

Открывается блокнотом. Одна буква — одна клетка поля, 15 строк сверху вниз.

| Знак | Что это |
|---|---|
| пробел | пустота |
| `X` | земля |
| `S` | камень, не разбивается |
| `B` | кирпич, большой герой разбивает |
| `?` | блок с монетой |
| `M` | блок с грибом |
| `p` | труба (рисуйте прямоугольником 2 клетки в ширину) |
| `o` | монета |
| `g` | гумба, ходит туда-сюда |
| `k` | черепаха |
| `=` | платформа, ездит влево-вправо |
| `^` | платформа, ездит вверх-вниз |
| `F` | флаг, конец уровня. Должен быть ровно один |
| `C` | замок |
| `c` `b` `h` | облако, куст, холм — только для вида |

Сохранили файл, вернулись в Unity, нажали Play — уровень уже новый.

**Проверить карту после правки:** в Unity верхнее меню
**Pixel Runner 999 → Проверить карты уровней**. Скажет, если строк стало
не 15, если попал непонятный знак или если яма шире пяти клеток —
такую не перепрыгнуть.

## Что внутри — для разработчика

- **Ни одного бинарного ассета.** Спрайты рисуются кодом (`PixelArt.cs`),
  звук и музыка синтезируются кодом (`Sfx.cs`). Папку `Assets/PixelRunner`
  можно скопировать в любой проект — ничего не отвалится, потому что нечему.
- **Ни одной сцены.** Игра поднимается из `Bootstrap.cs` через
  `[RuntimeInitializeOnLoadMethod]`, поэтому работает в пустой сцене любого
  свежего проекта и не требует настройки в инспекторе.
- **Обе системы ввода.** `Controls.cs` собирается и со старым Input Manager,
  и с новым Input System — ветка выбирается директивами компилятора.
- **Unity 6 и старее.** `Rigidbody2D.velocity` переименована в
  `linearVelocity`; всё обращение к скорости идёт через `Rb2D.Vel/SetVel`
  в `Cfg.cs`, где версия проверяется через `UNITY_6000_0_OR_NEWER`.
- **Все числа игры** — скорость, высота прыжка, гравитация, время уровня —
  в `Cfg.cs`, одним списком.

Файлы:

```
Assets/PixelRunner/
├── Scripts/
│   ├── Bootstrap.cs      точка входа, поднимает игру
│   ├── Cfg.cs            все числа + совместимость версий Unity
│   ├── Controls.cs       клавиатура, обе системы ввода
│   ├── Game.cs           состояния, жизни, очки, загрузка уровней
│   ├── Hud.cs            счёт и экраны (заставка, пауза, конец)
│   ├── PixelArt.cs       вся графика, рисуется кодом
│   ├── Sfx.cs            звуки и музыка, синтез кодом
│   ├── LevelBuilder.cs   текстовая карта → объекты сцены
│   ├── Player.cs         герой: бег, прыжок, урон, рост
│   ├── Enemy.cs          гумба и черепаха с панцирем
│   ├── Block.cs          кирпич, «?», камень
│   ├── Coin.cs · CoinPop.cs · Mushroom.cs · Platform.cs · Flag.cs
│   └── CameraFollow.cs   камера в границах уровня
├── Editor/LevelCheck.cs  проверка карт из меню
└── Resources/urovni/     три уровня текстом
instrumenty/sobrat-urovni.py   пересобрать карты скриптом, если правите
                               уровни не руками, а генератором
```

Папка `Packages/` и `ProjectSettings/ProjectVersion.txt` лежат рядом,
чтобы папку `pixel-runner-999` можно было открыть в Unity Hub напрямую
как готовый проект. Основной путь — всё-таки шаги 3–4 выше: свой пустой
проект плюс копирование `Assets/PixelRunner`, он не зависит от версии.

## Чего в игре нет

Записано честно, чтобы не обещать заказчику лишнего:

- нет сохранения результата между запусками — очки живут до закрытия;
- нет геймпада, только клавиатура;
- большой герой сделан увеличением спрайта, а не отдельной рисовкой;
- нет подводных и подземных уровней, только наземные;
- сборка под Windows или веб не делалась, игра запускается из редактора.
