# «Вайб Джампер» — игра-платформер на Unity

Двухмерный платформер в духе классических «Марио»: бежим направо, прыгаем
врагам на голову, бьём блоки снизу, собираем монеты, добегаем до флага.
Три уровня, два вида врагов, усилитель, жизни, счёт и рекорд.

Сделано с нуля 21.08.2026. Своя графика, своя музыка, чужого нет ничего.

---

## Что это даёт студии

Это витрина. Сайт показывает, что мы делаем сайты, а игра показывает,
что мы умеем ещё и то, что клиент не ждёт. Показывать её можно прямо
с экрана: запускается за минуту, объяснять ничего не надо.

**На сайте её пока нет.** Чтобы игра открывалась в браузере, Unity должен
собрать её в формат WebGL, а собранный файл — лечь на хостинг. Это
отдельная работа, она записана в `TASKS.md` как незакрытая.

## Как открыть игру на компьютере

Игру нужно открыть в программе Unity. Она бесплатная для нашего случая.

**Шаг 1.** В браузере откройте `https://unity.com/download` и скачайте
**Unity Hub**. Это маленькая программа-запускалка, через неё ставится
всё остальное.

**Что увидим:** скачается файл вроде `UnityHubSetup.exe`. Запустите его
и пройдите установку, ничего не меняя.

**Шаг 2.** Откройте Unity Hub, слева выберите **Installs**, нажмите
**Install Editor** и выберите версию **2022.3** (в списке она подписана
`LTS`). Нажмите **Install**.

**Что увидим:** пойдёт полоса загрузки. Это долго — несколько гигабайт,
20–40 минут на обычном интернете. Компьютер в это время свободен.

**Если в списке нет 2022.3** — возьмите любую версию с подписью `LTS`.
Игра проверена и на 2022.3, и на Unity 6.

**Шаг 3.** В Unity Hub слева выберите **Projects**, нажмите **Add** →
**Add project from disk** и укажите папку:

```
C:\vibe-digital999\igra-mario
```

**Что увидим:** в списке проектов появится строка `igra-mario`.

**Шаг 4.** Щёлкните по этой строке.

**Что увидим:** откроется Unity — это займёт минуту-две в первый раз,
он готовит проект. Потом появится большое окно с серым полем посередине.

**Шаг 5.** Нажмите треугольную кнопку **Play** вверху по центру окна.

**Что увидим:** тёмно-синий экран со звёздами и надписью
**ВАЙБ ДЖАМПЕР**. Нажмите пробел — начнётся игра.

**Если вместо игры красные строчки внизу** — напишите мне, что там
написано. Это ошибка сборки, чинится правкой файла.

## Как играть

| Клавиши | Что делают |
|---|---|
| Стрелки влево-вправо или `A` и `D` | идти |
| Пробел, `W` или стрелка вверх | прыгнуть |
| `Shift` | бежать (прыжок становится длиннее) |
| `Esc` или `P` | пауза |
| `M` | выключить и включить музыку |

Правила простые:

- **Прыжок на врага** — враг убит, вы отскакиваете. Держите кнопку
  прыжка в момент касания — отскок будет выше.
- **Касание врага сбоку** — потеряли усилитель. Если его не было —
  потеряли жизнь.
- **Удар головой по блоку с вопросом** — оттуда выпадает монета,
  усилитель или жизнь.
- **Кирпич разбивается только большим героем.** Маленький его
  просто подбрасывает.
- **Панцирь** после прыжка на него прячется. Толкните его сбоку —
  он полетит и снесёт всех врагов на пути. И вас тоже, если попадётесь.
  Через восемь секунд он встаёт обратно.
- **Сто монет — жизнь.**
- **Чем выше схватились за флагшток, тем больше очков.** Оставшееся
  время тоже идёт в счёт, по 10 очков за единицу.

Упали в яму или кончилось время — минус жизнь. Кончились жизни — игра
сначала. Рекорд сохраняется между запусками.

## Что внутри — карта для следующего чата

Проект **собирается кодом целиком**. Сцена `Assets/Scenes/Igra.unity`
пустая, и это намеренно: сцена Unity — большой файл, который нельзя
прочитать и починить в переписке, а код можно. Всю игру поднимает
`Bootstrap.cs` при нажатии Play, из любой сцены.

Ни одной картинки, ни одного звукового файла в проекте нет: спрайты
нарисованы буквами в `Art.cs`, звуки и музыка посчитаны формулами
в `Sfx.cs`.

| Файл | За что отвечает |
|---|---|
| `Bootstrap.cs` | точка входа: камера, физика, звук, правила |
| `GameManager.cs` | счёт, монеты, жизни, время, смена уровней, заставка |
| `Hud.cs` | всё, что нарисовано поверх игры |
| `PlayerController.cs` | герой: бег, прыжок, урон, рост, смерть |
| `Vrag.cs` | общее для врагов: ходьба, разворот, смерть |
| `Gribysh.cs` · `Pancir.cs` | два вида врагов |
| `Blok.cs` · `BlokVopros.cs` · `Kirpich.cs` | блоки, которые бьют снизу |
| `Moneta.cs` · `Usilitel.cs` · `MonetaVsplyv.cs` | что собирают |
| `Flag.cs` | конец уровня |
| `LevelData.cs` | **карты уровней буквами** |
| `LevelBuilder.cs` | превращает буквы в объекты сцены |
| `Art.cs` | вся графика |
| `Sfx.cs` | все звуки и музыка |
| `CameraFollow.cs` · `Parallax.cs` | камера и дальний план |
| `Layers.cs` | слои столкновений, менять вместе с `TagManager.asset` |
| `Sovmestimost.cs` | разница между Unity 2022 и Unity 6, вся в одном месте |

### Как поменять уровень

Уровни лежат в `Assets/Scripts/LevelData.cs` обычными строками.
Один символ — одна клетка:

```
.  пусто            #  земля           =  твёрдый блок
B  кирпич           ?  блок с монетой  M  блок с усилителем
U  блок с жизнью    o  монета
g  грибыш           k  панцирь
[ ] верх трубы      { } тело трубы
S  старт героя      F  флаг
c  облако           h  холм            v  куст
```

Правило одно, зато железное: **все строки одного уровня обязаны быть
одной длины**. Сборка проверяет это сама и пишет в консоль Unity, если
строка короче — но карта при этом уже поедет, так что лучше не сбивать.

Новый уровень = новый массив рядом с `Uroven3` плюс его имя в списке
`Vse` в начале файла. Всё остальное подхватится само.

### Цифры, которые стоит крутить первыми

В `PlayerController.cs` вверху собраны все настройки ощущения игры:
скорость шага и бега, высота прыжка, трение, поблажки на прыжок у края.
Меняете одну — проверяйте на прыжке через яму в три клетки, там видно
сразу всё.

## Чего в игре нет

Честный список, чтобы никто не искал:

- **Нет версии для браузера.** Нужна сборка WebGL и место на хостинге.
- **Нет сохранения прогресса.** Между запусками хранится только рекорд.
- **Нет управления с телефона.** Только клавиатура.
- **Нет боссов и подземных уровней.** Три наземных уровня.
- **Уровни не проверены живой игрой от начала до конца** — код собран
  и компилируется без ошибок, но пройти все три уровня руками ещё некому.
