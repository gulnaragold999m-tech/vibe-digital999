## Как поправить внутреннюю страницу

Текст страниц лежит в `src/pages/` — по файлу на страницу. Адреса,
заголовки и меню — в `src/pages.js`. Поправили, пересобрали:

```bash
npm run build
```

Команда перезапишет собранные папки внутри `public/`, а также
`public/sitemap.xml` и `public/llms.txt`. Прямая правка собранного
`index.html` пропадёт при следующей сборке — об этом написано в шапке
каждого такого файла.

Зачем так: шапка, подвал, форма и разметка для поисковиков у двух с лишним
десятков страниц одинаковые. Держать двадцать пять копий руками — значит
однажды поправить телефон в двадцати четырёх местах из двадцати пяти
и не заметить.

**Главная страница собой не собирается:** `public/index.html` правится
напрямую, стили и скрипты лежат внутри самого файла.

11.08.2026 в проекте некоторое время существовала вторая система сборки,
`tools/build-pages.js`. Она удалена, системе сборки быть одной. История
и причина — в `STATUS.md`.

## Как запустить у себя на компьютере

Один раз установить зависимости:

```bash
npm install
```

Запустить сайт:

```bash
npm start
```

Открыть в браузере: `http://localhost:3000`

## Про ключи

Настоящие ключи лежат в файле `.env`. Его нет в репозитории и не должно быть.
Чтобы создать свой — скопируйте `.env.example` в `.env` и подставьте значения.
