## Что сейчас сломано или не доделано

Порядок — по тому, сколько это стоит денег.

1. **Бота в Telegram нет.** Токен соседнего проекта занять нельзя:
   два опроса одним токеном убивают обоих. Нужен свой у BotFather.
2. **Бот ВК не понимает голосовые.** Человек пишет голосом — бот молчит
   вообще. Расшифровка у ВК есть, брать её код пока не умеет.
3. **В письме с заявкой нет даты и времени.** Открываешь письмо
   и не понимаешь, заявка свежая или недельной давности.
4. **Карта на странице контактов не показывается** — нет ключей
   Яндекс Карт.
5. **В портфолио нет картинок**, карточки текстовые.
6. **Домен `vibe-digital999.online`** не переадресован на основной.

## Как сайт попадает в интернет

**GitHub и живой сайт — разные места.** Пуш в GitHub ничего не публикует.

Выкатка **с телефона, без компьютера:** GitHub → вкладка **Actions** →
«Выкатить сайт на Amvera» → **Run workflow** → выбрать ветку
`claude/multipage-website-okje3k`. Занимает одну-две минуты.

Само по себе ничего не выкатывается: на автомат намеренно не повешено,
чтобы случайная правка не уехала на живой сайт.

## Три файла памяти — это для чата, не для вас

| Файл | Для кого | Что внутри |
|---|---|---|
| `CLAUDE.md` | для чата | правила: как работать, как выкатывать, чего не делать |
| `STATUS.md` | для чата | где что лежит, карта веток, чего ещё нет |
| `TASKS.md` | для чата | журнал по дням, две с лишним тысячи строк |
| `README.md` | **для вас** | эта страница |

Журнал разросся до размеров, которые человеку не прочитать, — и это
не поломка, а его назначение: он написан для беседы, которая начинается
с нуля и должна за минуту понять, где остановились. Читать его вам
не нужно. **Если журнал понадобился вам — значит, чего-то не хватает
здесь, и это надо дописать сюда.**

## Запуск у себя на компьютере

```bash
npm install
```

```bash
npm start
```

Открыть `http://localhost:3000`.

Настоящие ключи лежат в `.env`, его в репозитории нет и быть не должно.
Образец — `.env.example`.
