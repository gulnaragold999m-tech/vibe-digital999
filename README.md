# Vibe Digital 999

Сайт агентства вайбкодинга. Домен: `vibe-digital999.ru`.

## Структура папки

```
vibe-digital999/
├── CLAUDE.md              правила проекта (читать первым)
├── README.md              этот файл
├── docs/
│   ├── 01-ARCHITECTURE.md структура сайта, блоки, экраны
│   ├── 02-BRAND.md        цвета, шрифты, тон общения
│   ├── 03-CONTENT.md      тексты, офферы, вопросы-ответы
│   └── 04-DEPLOY-AMVERA.md как выложить сайт на Amvera
├── public/                то, что видит посетитель
│   ├── index.html         главная страница (стили и скрипты внутри файла)
│   ├── uslugi/            страницы услуг — СОБИРАЮТСЯ, руками не править
│   ├── portfolio/         страницы кейсов — СОБИРАЮТСЯ, руками не править
│   ├── sitemap.xml        карта сайта — СОБИРАЕТСЯ, руками не править
│   └── assets/            логотип, иконки, шрифты, site.css и site.js
├── tools/
│   ├── pages-data.js      ТЕКСТ страниц услуг и кейсов — правится здесь
│   └── build-pages.js     сборка страниц и карты сайта
├── api/                   обработка заявок с формы
├── server.js              сервер: отдаёт сайт и принимает заявки
├── package.json           список зависимостей
└── .env.example           образец файла с ключами
```

## Как поправить страницу услуги

Текст всех страниц услуг и кейсов лежит в одном файле — `tools/pages-data.js`.
Поправили текст, пересобрали:

```bash
node tools/build-pages.js
```

Команда перезапишет `public/uslugi`, `public/portfolio` и `public/sitemap.xml`.
Прямая правка собранных `index.html` пропадёт при следующей сборке — об этом
написано в шапке каждого такого файла.

Зачем так: шапка, подвал, форма и разметка для поисковиков у семи страниц
одинаковые. Держать семь копий руками — значит однажды поправить телефон
в шести местах из семи и не заметить.

Главная страница собой не собирается: `public/index.html` правится напрямую.

## Как запустить у себя на компьютере

Один раз установить зависимости:

```bash
npm install
```

Запустить сайт:

```bash
npm start
```

Открыть в браузере: `http://localhost:3000`

## Про ключи

Настоящие ключи лежат в файле `.env`. Его нет в репозитории и не должно быть.
Чтобы создать свой — скопируйте `.env.example` в `.env` и подставьте значения.
