# Vibe Digital 999

Сайт агентства вайбкодинга. Домен: `vibe-digital999.ru`.

## Структура папки

```
vibe-digital999/
├── CLAUDE.md              правила проекта (читать первым)
├── README.md              этот файл
├── docs/
│   ├── 01-ARCHITECTURE.md структура сайта, блоки, экраны
│   ├── 02-BRAND.md        цвета, шрифты, тон общения
│   ├── 03-CONTENT.md      тексты, офферы, вопросы-ответы
│   └── 04-DEPLOY-AMVERA.md как выложить сайт на Amvera
├── public/                то, что видит посетитель
│   ├── index.html         главная страница
│   └── assets/            логотип, картинки, иконки
├── api/                   обработка заявок с формы
├── server.js              сервер: отдаёт сайт и принимает заявки
├── package.json           список зависимостей
└── .env.example           образец файла с ключами
```

## Как запустить у себя на компьютере

Один раз установить зависимости:

```bash
npm install
```

Запустить сайт:

```bash
npm start
```

Открыть в браузере: `http://localhost:3000`

## Про ключи

Настоящие ключи лежат в файле `.env`. Его нет в репозитории и не должно быть.
Чтобы создать свой — скопируйте `.env.example` в `.env` и подставьте значения.
