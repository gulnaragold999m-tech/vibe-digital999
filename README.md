# Vibe Digital 999

Сайт агентства вайбкодинга. Домен: `vibe-digital999.ru`.

## Структура папки

```
vibe-digital999/
├── CLAUDE.md              правила проекта — читать первым
├── STATUS.md              карточка проекта: где что лежит, карта веток
├── TASKS.md               журнал по дням: что делали, что висит
├── README.md              этот файл
├── docs/                  01 структура · 02 бренд · 03 тексты ·
│                          04 деплой · 05–12 SEO, агент, боты
├── src/                   ИСХОДНИКИ страниц — правится здесь
│   ├── pages.js           адреса, заголовки, описания, даты
│   ├── partials/          шапка, подвал, <head>, форма заявки
│   └── pages/*.html       тексты страниц
├── build.js               сборка src/ → public/ (+ sitemap.xml, llms.txt)
├── public/                СОБРАННОЕ, руками не править — сотрёт сборкой
│   ├── index.html         главная и privacy.html — исключение, они ручные
│   └── assets/            логотип, картинки, иконки, site.css, скрипты
├── api/                   заявки, ассистент, боты ВК и Telegram
├── server.js              сервер: отдаёт сайт и принимает заявки
├── package.json           зависимости, build висит на prestart
└── .env.example           образец файла с ключами
```

Собрать страницы после правки исходников:

```bash
npm run build
```

Папки `tools/` в рабочей версии нет. Если она попалась — это второй
генератор страниц, сделанный по ошибке поверх существующего.
Разбор — в `STATUS.md`, раздел «Две системы сборки».

## Как запустить у себя на компьютере

Один раз установить зависимости:

```bash
npm install
```

Запустить сайт:

```bash
npm start
```

Открыть в браузере: `http://localhost:3000`

## Про ключи

Настоящие ключи лежат в файле `.env`. Его нет в репозитории и не должно быть.
Чтобы создать свой — скопируйте `.env.example` в `.env` и подставьте значения.
