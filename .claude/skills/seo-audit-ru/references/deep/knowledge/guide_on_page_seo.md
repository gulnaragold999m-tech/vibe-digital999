## **1. Что такое On-Page SEO и его элементы**

### **1.1. Определение**

- On-Page SEO — оптимизация **элементов на странице** для улучшения ранжирования.
- Включает контент, HTML-элементы, структуру страницы.
- В отличие от off-page (внешние сигналы) и technical (инфраструктура).

### **1.2. Ключевые элементы**

| Категория | Элементы |
|-----------|----------|
| **HTML** | Title tag, meta description, headers, alt text |
| **Content** | Quality, length, keywords, freshness |
| **Structure** | URL, internal links, breadcrumbs |
| **UX** | Readability, formatting, multimedia |

### **1.3. Приоритеты**

1. **Title tag** — самый важный on-page фактор.
2. **H1 и заголовки** — структура и релевантность.
3. **Quality content** — ответ на intent пользователя.
4. **Internal links** — распределение авторитета.

**Вывод:** On-Page SEO — это контроль над тем, как Google понимает и отображает страницу.

## **2. Title Tags и их оптимизация**

### **2.1. Роль Title Tag**

- Title tag — **самый важный** on-page SEO элемент.
- Отображается в:
  - SERP как кликабельный заголовок
  - Browser tab
  - Social shares (если нет og:title)

### **2.2. Best Practices**

- **Длина:** 50-60 символов (до обрезки в SERP).
- **Primary keyword** — в начале title.
- **Уникальность** — каждая страница имеет уникальный title.
- **Бренд** — в конце, через | или -.

**Формула:**
```
Primary Keyword — Secondary Keyword | Brand Name
```

**Пример:**
```
Running Shoes for Marathon Training — Nike Official Store
```

### **2.3. Чего избегать**

- ⚠️ Keyword stuffing: `SEO SEO SEO Guide SEO Tips SEO`
- ⚠️ Дубликаты: один title на все страницы.
- ⚠️ Vague titles: `Home`, `Untitled`.
- ⚠️ ALL CAPS или эмодзи (если не бренд).

### **2.4. Google и Title Links**

- Google может **переписать** title в SERP.
- Источники для переписывания:
  - H1 на странице
  - Anchor text ссылок
  - Content страницы

> Google автоматически генерирует title links, учитывая контент страницы и ссылки на неё.

**Вывод:** Уникальный, описательный title с keyword в начале = основа on-page SEO.

## **3. Meta Descriptions для CTR**

### **3.1. Роль Meta Description**

- Meta description **не влияет на ранжирование напрямую**.
- Влияет на **CTR** — кликабельность в SERP.
- Это "pitch" для пользователя.

### **3.2. Best Practices**

- **Длина:** 150-160 символов (desktop), 120 (mobile).
- **Call-to-action:** Побуждай к клику.
- **Unique selling point:** Почему эта страница лучше?
- **Keywords:** Выделяются жирным в SERP при совпадении.

**Формула:**
```
[What] + [Benefit] + [CTA]
```

**Пример:**
```
Complete guide to running shoe selection. Learn how to choose the perfect fit for your marathon training. Shop now with free returns.
```

### **3.3. Чего избегать**

- ⚠️ Дублирование description на разных страницах.
- ⚠️ Списки ключевых слов вместо текста.
- ⚠️ Неточное описание контента.
- ⚠️ Отсутствие description (Google сгенерирует сам).

### **3.4. Когда Google игнорирует description**

- Если description не соответствует запросу, Google берёт фрагмент из контента.
- Для разных запросов может показывать разные snippets.

**Вывод:** Meta description = реклама страницы. Оптимизируй для CTR, не для rankings.

## **4. Heading Structure (H1-H6)**

### **4.1. Иерархия заголовков**

```
H1: Главный заголовок страницы (один)
  H2: Основные разделы
    H3: Подразделы
      H4-H6: Дополнительная вложенность
```

### **4.2. H1 — главный заголовок**

- **Один H1 на страницу** — best practice.
- Содержит primary keyword.
- Отражает основную тему страницы.
- Может отличаться от title tag (но должен быть согласован).

### **4.3. H2-H6 — структура контента**

- Используй для логического деления контента.
- Keywords в заголовках — естественно, без stuffing.
- Помогает:
  - Пользователям — scanability.
  - Google — понимание структуры.
  - Featured Snippets — Google часто берёт H2/H3.

### **4.4. Best Practices**

- Заголовки описывают содержимое раздела.
- Логическая иерархия: не перескакивай с H2 на H5.
- Используй для структуры, не для стилизации.

**Вывод:** H1-H6 = outline документа. Помогает и пользователям, и Google.

## **5. Content Optimization**

### **5.1. Search Intent Matching**

| Intent | Описание | Формат контента |
|--------|----------|-----------------|
| **Informational** | Хочет узнать | Guides, how-to, FAQ |
| **Navigational** | Ищет сайт/бренд | Homepage, brand pages |
| **Transactional** | Готов купить | Product pages, pricing |
| **Commercial** | Сравнивает | Reviews, comparisons |

> Первый шаг оптимизации — понять intent и создать соответствующий контент.

### **5.2. Keyword Placement**

- **Title tag** — primary keyword в начале.
- **H1** — primary keyword.
- **First 100 words** — упомяни primary keyword.
- **H2/H3** — secondary keywords и LSI.
- **Body text** — natural usage, без stuffing.
- **Image alt** — descriptive, с keywords где уместно.

### **5.3. Content Quality (E-E-A-T)**

- **Comprehensiveness:** Полностью отвечает на вопрос.
- **Accuracy:** Фактически точный контент.
- **Freshness:** Регулярно обновляй.
- **Originality:** Уникальный, не скопированный.
- **Expertise:** Демонстрируй знание темы.

### **5.4. Readability**

- Короткие параграфы (2-4 предложения).
- Bullet points и numbered lists.
- Визуальные элементы (images, tables, charts).
- Simple language (если не technical audience).

**Вывод:** Intent matching + keyword placement + E-E-A-T = оптимизированный контент.

## **6. Internal Linking Strategy**

### **6.1. Зачем нужны internal links**

- **Discovery:** Помогают Googlebot найти страницы.
- **Authority distribution:** Передают PageRank.
- **Context:** Показывают семантические связи.
- **UX:** Помогают пользователям навигировать.

### **6.2. Anchor Text**

- **Descriptive:** Описывает целевую страницу.
- **Varied:** Не повторяй один anchor для всех ссылок.
- **Natural:** Вписывается в контекст.

**Хорошо:** `Learn more about [on-page SEO techniques]`
**Плохо:** `Click [here] for more information`

### **6.3. Link Patterns**

- **Pillar-Cluster:** Pillar page ↔ Cluster pages.
- **Hierarchical:** Category → Subcategory → Product.
- **Related Content:** "See also", "Related articles".

### **6.4. Best Practices**

- Ссылайся с авторитетных страниц на новые/важные.
- Избегай orphan pages (без входящих ссылок).
- Regularly audit internal links на broken.
- Не более 100-150 ссылок на странице.

**Вывод:** Internal links = distribution авторитета + contextual relevance.

## **7. Image Optimization**

### **7.1. Alt Text**

- **Описательный:** Что изображено на картинке.
- **Keywords:** Где уместно, естественно.
- **Accessibility:** Для screen readers.

**Хорошо:** `Marathon runner crossing finish line at Boston Marathon 2024`
**Плохо:** `image1.jpg` или `running shoes SEO keywords marathon`

### **7.2. File Names**

- Descriptive: `red-running-shoes-nike-pegasus.jpg`
- Hyphens, не underscores.
- Lowercase.

### **7.3. File Size и Format**

| Format | Когда использовать |
|--------|-------------------|
| **WebP** | Default choice — best compression |
| **AVIF** | Newer, better compression, less support |
| **JPEG** | Photos without transparency |
| **PNG** | Graphics with transparency |
| **SVG** | Icons, logos, illustrations |

### **7.4. Lazy Loading**

- Загружай изображения по мере scroll.
- `loading="lazy"` attribute.
- Не применяй к above-the-fold images.

### **7.5. Image Sitemaps**

- Включай изображения в sitemap для лучшего discovery.
- Особенно важно для e-commerce и portfolio сайтов.

**Вывод:** Descriptive alt + optimized size + proper format = SEO-friendly images.

## **Ключевые тезисы**

1. **Title tag** — самый важный on-page фактор. Keyword в начале.
