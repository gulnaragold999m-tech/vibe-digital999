## **1. Что такое Local SEO и его особенности**

### **1.1. Определение**

- Local SEO — оптимизация для **локального поиска** (с геопривязкой).
- Цель: появление в Local Pack, Google Maps, local organic results.
- Критично для бизнесов с физическим присутствием.

### **1.2. Local vs Organic SEO**

| Аспект | Organic SEO | Local SEO |
|--------|------------|-----------|
| **Географияя** | Глобальный/национальный | Локальный |
| **Главный результат** | Blue links | Local Pack (3-pack) |
| **Ключевая платформа** | Website | Google Business Profile |
| **Основные сигналы** | Content, links | Proximity, reviews, citations |

### **1.3. Local Intent Queries**

- Явные: `plumber near me`, `pizza in Brooklyn`
- Неявные: `coffee shop`, `dentist` (Google определяет intent по локации)
- "Near me" запросы выросли на 150%+ за последние годы.

**Вывод:** Local SEO — отдельная дисциплина со своими правилами и сигналами.

## **2. Google Business Profile оптимизация**

### **2.1. Что такое GBP**

- Google Business Profile (ранее Google My Business) — бесплатный профиль бизнеса.
- Появляется в:
  - Local Pack
  - Google Maps
  - Knowledge Panel

### **2.2. Claim и Verification**

1. Создай или claim профиль на business.google.com.
2. Пройди верификацию (postcard, phone, email, video).
3. Получи полный доступ к управлению.

### **2.3. Обязательные элементы GBP**

| Элемент | Рекомендации |
|---------|-------------|
| **Business Name** | Точное название без keyword stuffing |
| **Address** | Полный, точный адрес |
| **Phone** | Локальный номер (не 800) |
| **Hours** | Актуальные часы работы |
| **Categories** | Primary + secondary categories |
| **Description** | 750 символов, keywords естественно |
| **Website URL** | Ссылка на сайт |
| **Photos** | Качественные фото (10+) |

### **2.4. Дополнительные оптимизации**

- **Posts:** Регулярные обновления (events, offers, updates).
- **Products/Services:** Добавь с описаниями и ценами.
- **Attributes:** Amenities, accessibility, payment methods.
- **Q&A:** Отвечай на вопросы, добавляй свои FAQ.
- **Messaging:** Включи для прямой коммуникации.

> ⚠️ Не добавляй keywords в название бизнеса — это нарушение guidelines.

**Вывод:** GBP — фундамент Local SEO. Полная, точная, регулярно обновляемая информация.

## **3. Local Pack и Map Pack**

### **3.1. Что такое Local Pack**

- Local Pack (3-pack) — блок из 3 локальных результатов в SERP.
- Появляется для запросов с локальным intent.
- Включает: название, рейтинг, адрес, часы, телефон.

### **3.2. Факторы ранжирования в Local Pack**

| Фактор | Описание | Влияние |
|--------|----------|---------|
| **Proximity** | Расстояние до пользователя | Высокое |
| **Relevance** | Соответствие запросу | Высокое |
| **Prominence** | Известность бизнеса | Высокое |
| **Reviews** | Количество и качество отзывов | Высокое |
| **GBP Signals** | Полнота профиля, активность | Среднее |
| **On-Page** | Local landing pages, NAP | Среднее |
| **Links** | Local links, citations | Среднее |

### **3.3. Proximity**

- Google учитывает расстояние от пользователя до бизнеса.
- Для запросов без конкретной локации — используется текущая геолокация.
- Proximity нельзя "оптимизировать" — фокусируйся на других факторах.

### **3.4. Prominence**

- Известность бизнеса offline и online.
- Факторы: brand mentions, press coverage, reviews, links.
- Крупные бренды ранжируются выше.

**Вывод:** Local Pack = proximity + relevance + prominence. Оптимизируй то, что можешь контролировать.

## **4. NAP Consistency и Citations**

### **4.1. Что такое NAP**

- **N**ame, **A**ddress, **P**hone — базовая информация о бизнесе.
- Должна быть **идентичной** везде.
- Несоответствия путают Google и пользователей.

### **4.2. Примеры несоответствий**

| Проблема | Пример |
|----------|--------|
| **Сокращения** | "Street" vs "St." vs "St" |
| **Suite numbers** | "Suite 100" vs "#100" vs отсутствует |
| **Phone format** | "(555) 123-4567" vs "555-123-4567" |
| **Business name** | "Joe's Pizza" vs "Joe's Pizza Inc" |

### **4.3. Citations**

- Citation — упоминание NAP на внешнем сайте.
- **Structured citations:** Directories (Yelp, Yellow Pages, industry-specific).
- **Unstructured citations:** Blog posts, news articles.

### **4.4. Топ-директории для citations**

| Категория | Платформы |
|-----------|-----------|
| **General** | Yelp, Yellow Pages, BBB, Facebook |
| **Industry-specific** | TripAdvisor (travel), Healthgrades (medical) |
| **Local** | Chamber of Commerce, local newspapers |
| **Data aggregators** | Factual, Localeze, Infogroup, Acxiom |

### **4.5. Citation Audit**

1. Найди все существующие citations.
2. Проверь NAP consistency.
3. Исправь несоответствия.
4. Добавь на недостающие платформы.

**Вывод:** NAP consistency = доверие Google. Inconsistency = confusion и потеря rankings.

## **5. Local Reviews и Reputation**

### **5.1. Почему reviews важны**

- Reviews — один из **топ-3 факторов** Local Pack.
- Влияют на:
  - Rankings в Local Pack
  - CTR (click-through rate)
  - Conversion rate
  - Trust (E-E-A-T)

### **5.2. Review Signals**

| Сигнал | Описание |
|--------|----------|
| **Quantity** | Общее количество отзывов |
| **Velocity** | Скорость получения новых |
| **Diversity** | Отзывы на разных платформах |
| **Recency** | Свежесть отзывов |
| **Rating** | Средний рейтинг |
| **Keywords** | Упоминание услуг в отзывах |

### **5.3. Стратегия получения reviews**

- **Ask:** Просите отзывы после успешного взаимодействия.
- **Make it easy:** Дайте прямую ссылку на форму отзыва.
- **Timing:** Просите в момент peak satisfaction.
- **Follow-up:** Email reminder через 1-2 дня.

> ⚠️ Не покупай отзывы, не предлагай incentives — это нарушение.

### **5.4. Ответы на reviews**

- **Positive:** Благодарность, персонализация.
- **Negative:** Извинение, решение проблемы, приглашение offline.
- **Fake:** Сообщение платформе, вежливый ответ.

**Вывод:** Reviews = social proof + ranking signal. Собирай proactively, отвечай на все.

## **6. Local Content Strategy**

### **6.1. Local Landing Pages**

- Создавай отдельные страницы для каждой локации.
- Включай: NAP, local content, testimonials, directions.
- Unique content для каждой — не дубликаты.

### **6.2. Структура Local Landing Page**

```
H1: [Service] in [City]
- Unique intro paragraph
- Services offered
- NAP (schema markup)
- Embedded Google Map
- Local testimonials
- Local photos
- CTA (call, visit, book)
```

### **6.3. Local Content Ideas**

- Local events coverage.
- Local guides ("Best X in [City]").
- Community involvement stories.
- Local case studies.
- Partnerships с local businesses.

### **6.4. Schema Markup для Local**

```json
{
  "@context": "https://schema.org",
  "@type": "LocalBusiness",
  "name": "Joe's Pizza",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "123 Main St",
    "addressLocality": "Brooklyn",
    "addressRegion": "NY",
    "postalCode": "11201"
  },
  "telephone": "+1-555-123-4567",
  "openingHours": "Mo-Su 11:00-23:00",
  "geo": {
    "@type": "GeoCoordinates",
    "latitude": "40.6892",
    "longitude": "-73.9857"
  }
}
```

**Вывод:** Local content = unique pages per location + local relevance + schema markup.

## **7. Local Link Building**

### **7.1. Типы local links**

| Источник | Пример |
|----------|--------|
| **Chambers of Commerce** | Членство |
| **Local newspapers** | Coverage, sponsorships |
| **Local blogs** | Guest posts, features |
| **Sponsorships** | Local events, sports teams |
| **Partnerships** | Complementary businesses |
| **Universities** | Alumni pages, sponsorships |
| **Nonprofits** | Donations, volunteering |

### **7.2. Стратегии**

- **Community involvement:** Спонсируй местные события.
- **Scholarships:** Создай local scholarship — .edu links.
- **Local PR:** Newsworthy stories для local media.
- **Partnerships:** Cross-promotion с local businesses.
- **Expert contributions:** Комментарии для local journalists.

### **7.3. Особенности**

- Локальные ссылки **более релевантны** для local rankings.
- Качество > количество.
- Contextual links > directory listings.

**Вывод:** Local links = community involvement + genuine relationships.
