## **1. Что такое SEO и зачем он нужен**

### **1.1. Определение SEO**

- SEO (Search Engine Optimization) — это процесс помощи поисковым системам **понять ваш контент** и помощи пользователям **найти ваш сайт** через поиск.
- SEO — это **не манипуляция алгоритмами**, а сотрудничество с поисковыми системами.
- Нет секретов для автоматического первого места — есть **лучшие практики**.

> SEO is about helping search engines understand your content, and helping users find your site.

### **1.2. Для кого это руководство**

- Владельцы бизнеса, маркетологи, веб-мастера.
- Все, кто управляет, монетизирует или продвигает контент через Google Search.

### **1.3. Search Essentials как фундамент**

- Search Essentials — базовые требования для попадания в индекс Google.
- Соблюдение Search Essentials **не гарантирует** попадание в индекс, но **увеличивает шансы**.
- SEO — следующий шаг после выполнения базовых требований.

**Вывод:** SEO — это не хаки и трюки, а системная работа над улучшением понимания контента поисковыми системами.

## **2. Как работает Google Search: crawling, indexing, serving**

### **2.1. Три этапа работы Google**

| Этап | Описание | Ключевые аспекты |
|------|----------|------------------|
| **Crawling** | Googlebot находит и скачивает страницы | Через ссылки, sitemap, прямые запросы |
| **Indexing** | Анализ и хранение контента в базе | Определение каноникала, категоризация |
| **Serving** | Выдача результатов на запросы | Учёт локации, устройства, истории |

### **2.2. Crawling (Сканирование)**

- Googlebot автоматически обходит веб, находя страницы через ссылки.
- Скачивает HTML, CSS, JavaScript, изображения, видео.
- Определяет приоритеты: что сканировать и как часто.

### **2.3. Indexing (Индексирование)**

- Анализ содержимого: текст, изображения, видео.
- Определение **canonical URL** — главной версии страницы.
- Хранение в индексе Google.
- ⚠️ **Важно:** Не все просканированные страницы индексируются!

### **2.4. Serving (Выдача)**

- Сопоставление запроса пользователя с проиндексированными страницами.
- Учёт контекста: локация, устройство, язык, история.
- Формирование SERP с разными типами результатов.

> Google does not accept payment for crawling, indexing, or ranking. There's no guarantee that content will be crawled, indexed, or served.

**Вывод:** Понимание трёх этапов позволяет диагностировать проблемы: страница не сканируется? не индексируется? не ранжируется?

## **3. Как помочь Google найти ваш контент**

### **3.1. Основные способы обнаружения**

- **Внутренние ссылки:** Googlebot следует по ссылкам с уже известных страниц.
- **Sitemap:** XML-файл со списком важных страниц.
- **Google Search Console:** Прямой запрос на индексацию.

### **3.2. Sitemaps**

- Sitemap — важнейший инструмент для сообщения Google о важных страницах.
- Особенно критичен для:
  - Сайтов с динамически меняющимся контентом.
  - Страниц, которые плохо связаны внутренними ссылками.
  - Нетекстового контента (изображения, видео).

- Google **приоритизирует** crawling страниц из sitemap, но не ограничивается ими.

### **3.3. Robots.txt**

- Используй для **предотвращения crawling** определённых разделов.
- **Не используй** robots.txt для предотвращения индексации — для этого есть `noindex`.
- Блокируй дубликаты и неважные ресурсы (иконки, мелкие изображения).

### **3.4. Crawlable Links**

- Используй стандартные `<a>` элементы с `href` атрибутами.
- Избегай JavaScript-событий без HTML-ссылок.
- Для мобильной и десктоп версий — одинаковый набор ссылок.

> Ensure your links are crawlable. Use `<a>` elements with `href` attributes.

**Вывод:** Sitemap + правильные внутренние ссылки + robots.txt = контролируемое сканирование.

## **4. Как организовать контент для индексации**

### **4.1. Иерархия и структура**

- Используй заголовки (H1, H2, H3) для создания **иерархической структуры**.
- Структура помогает:
  - Пользователям — легче навигировать.
  - Google — понимать организацию документа.

### **4.2. URL-структура**

- Используй **простую, логичную структуру URL**.
- Хорошо: `/products/shoes/running-shoes`
- Плохо: `/p?id=12345&cat=7`

### **4.3. Canonicalization**

- Google определяет **canonical URL** — главную версию страницы.
- Используй `rel="canonical"` для явного указания.
- Избегай дублирования контента на разных URL.

### **4.4. Mobile-First Indexing**

- Google индексирует **мобильную версию** как основную.
- Убедись, что мобильная версия содержит весь важный контент.
- Одинаковые ссылки на мобильной и десктоп версиях.

**Вывод:** Логичная структура + правильные canonical + mobile-first = эффективная индексация.

## **5. Как влиять на отображение в поиске**

### **5.1. Title Links**

- Google автоматически генерирует title links из:
  - `<title>` элемента
  - Визуальных заголовков (`<h1>`)
  - `og:title` meta tag
  - Anchor text ссылок на страницу

- **Best practices:**
  - Уникальный и описательный title для каждой страницы.
  - Включай ключевые слова, но не переспамливай.
  - Точно отражай содержимое страницы.

### **5.2. Snippets (Сниппеты)**

- Snippet — краткое описание страницы в результатах поиска.
- Источники snippet:
  - Контент страницы.
  - Meta description.

- **Best practices для meta description:**
  - Краткое (1-2 предложения), уникальное описание.
  - Включай самые релевантные points страницы.
  - Используй как "pitch" для пользователя.

> A meta description is like a pitch that convinces the user that the page is exactly what they're looking for.

### **5.3. Rich Results**

- Structured data позволяет получить **расширенные результаты**:
  - Рейтинги и отзывы.
  - Цены и наличие товаров.
  - FAQ accordions.
  - Рецепты, события, вакансии.

### **5.4. Knowledge Panels**

- Для бизнесов: claim **Google Business Profile**.
- Для сущностей: structured data и связи с Wikipedia/Wikidata.

**Вывод:** Title + snippet + structured data = контроль над отображением в SERP.

## **6. Как управлять поведением поисковых систем**

### **6.1. Robots Meta Tags**

| Директива | Описание |
|-----------|----------|
| `index/noindex` | Разрешить/запретить индексацию |
| `follow/nofollow` | Переходить/не переходить по ссылкам |
| `nosnippet` | Не показывать snippet |
| `max-snippet:[number]` | Ограничить длину snippet |
| `max-image-preview` | Размер превью изображений |

### **6.2. Link Attributes**

| Атрибут | Когда использовать |
|---------|-------------------|
| `rel="nofollow"` | Ссылки на ненадёжные ресурсы |
| `rel="sponsored"` | Платные/рекламные ссылки |
| `rel="ugc"` | User-generated content (комментарии) |

- Используй для **управления передачей авторитета**.
- Автоматически добавляй к UGC-ссылкам через CMS.

### **6.3. Search Console**

- **Обязательный инструмент** для:
  - Проверки индексации.
  - Диагностики проблем.
  - Отправки sitemap.
  - Мониторинга производительности.

**Вывод:** Meta tags + link attributes + Search Console = полный контроль над поведением Google.

## **7. Создание полезного контента (People-First)**

### **7.1. Принцип People-First**

> SEO can be a helpful activity when it is applied to people-first content, rather than search engine-first content.

- Контент должен создаваться **для людей**, не для алгоритмов.
- Оптимизация под пользователя = оптимизация под Google.

### **7.2. E-E-A-T Framework**

| Компонент | Описание |
|-----------|----------|
| **Experience** | Личный опыт автора с темой/продуктом |
| **Expertise** | Глубокие знания в предметной области |
| **Authoritativeness** | Признание как авторитетного источника |
| **Trustworthiness** | Доверие к странице и сайту |

- Критически важен для **YMYL-тем** (здоровье, финансы, безопасность).

### **7.3. Критерии качественного контента**

- Уникальный, ценный, compelling контент.
- Понятный для разных уровней аудитории (новички vs эксперты).
- Структурированный с заголовками и параграфами.
- Регулярно обновляемый.

### **7.4. Чего избегать**

- ⚠️ Дублированный или thin content.
- ⚠️ Keyword stuffing.
- ⚠️ AI-generated слоп без экспертной редактуры.
- ⚠️ Контент, созданный только для ранжирования.

**Вывод:** People-first + E-E-A-T = устойчивый органический рост.

## **Ключевые тезисы**

1. **SEO — это сотрудничество**, не манипуляция. Помогай Google понять твой контент.
2. **Три этапа Google:** crawling → indexing → serving. Проблемы на каждом этапе требуют разных решений.
3. **Sitemaps критичны** для обнаружения страниц, особенно для динамического контента.
4. **Title и snippet** — первое впечатление. Оптимизируй как "pitch" для пользователя.
5. **Structured data** расширяет возможности отображения в SERP.
6. **E-E-A-T** — фундамент доверия, критичен для YMYL-тем.
7. **People-first** — единственный устойчивый подход к SEO.
