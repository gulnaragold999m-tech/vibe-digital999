# Журнал — НАЗВАНИЕ ОРГАНИЗАЦИИ

> Шаблон. Заменить всё заглавными, удалить эту строку.

Что делали по дням. Пишется **для следующей беседы**, а не для
владелицы: её страница — `README.md`.

Дописывать снизу, никогда не переписывать. История нужна: по ней видно,
что уже пробовали и почему отказались.

## Шаблон записи — копировать целиком

```
## ЧИСЛО МЕСЯЦА

**Цель дня:** одной строкой — зачем мы это делали.

**Сделано:**
- [x] `a1b2c3d` что изменилось и в каком файле

**Остановились на:** что делали в последнюю минуту беседы и какой
следующий шаг. Написать так, чтобы чужой чат продолжил, не задав
владелице ни одного вопроса.

**Ждём от владелицы:**
- [ ] что она делает руками: ключ, галочка, переменная

**Не доделано в коде:**
- [ ] что осталось
```

## Правила, они же главные

- **`[x]` ставится не когда код написан, а когда результат виден:**
  на живом сайте, в Вебмастере, в Метрике, в Яндекс Бизнесе.
  «Написал» и «работает» — разные вещи.
- **Незакрытое не удалять никогда.** `- [ ]` и есть напоминание.
  Уберёшь — задача исчезнет из мира.
- **У каждой строчки «сделано» — короткий хэш коммита**, семь знаков,
  первым в строке. Берётся так:
  `git log --date=format:'%d.%m %H:%M' --format='%cd  %h  %s' -10`
  Без хэша журнал нельзя сверить с историей, а на слово он не сверяется:
  журнал пишется своими словами, коммит — своим заголовком.

Проверка, что ничего не потеряно:

```
git log --format='%h %s' --since='7 days ago'
```

Каждый хэш из ответа обязан встречаться в этом файле. Не встречается —
работа сделана и не записана.
