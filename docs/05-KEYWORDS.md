# 05 — Запросы, по которым нас должны находить

Составлено 1 августа 2026 по методике из «Роли Тексты / seo_manager».

## Главный вывод

Слово **«вайбкодинг» почти никто не ищет.** Это термин из нашего мира,
а не из мира клиента. Предприниматель, которому нужен сайт, набирает
«заказать лендинг» или «сколько стоит сайт».

Поэтому «вайбкодинг» остаётся в бренде и на первом экране, но в заголовке
страницы, в описании и в названиях блоков стоят слова, которые люди
действительно набирают.

## Что мы продаём глазами клиента

| Мы называем | Клиент ищет |
|-------------|-------------|
| Вайбкодинг | разработка сайта на заказ |
| Промо-лендинг | заказать лендинг под ключ |
| Лид-бот | разработка телеграм бота |
| ИИ-агент | чат бот для бизнеса |
| Комплексная автоматизация | автоматизация бизнес процессов |

## Запросы по намерению

Намерение важнее частотности. Человек, набравший «что такое чат-бот»,
читает и уходит. Человек, набравший «заказать чат-бота цена», готов платить.
Реклама и главная страница должны ловить второго.

### Готов купить — сюда ведём рекламу

- разработка сайта на заказ
- заказать лендинг
- заказать сайт под ключ
- разработка телеграм бота на заказ
- заказать чат бота для бизнеса
- создание сайта цена
- разработка сайта стоимость
- чат бот для бизнеса под ключ
- ии агент для бизнеса заказать
- автоматизация бизнес процессов под ключ
- разработка сайта без конструктора
- сайт на чистом коде заказать

### Сравнивает подрядчиков — сюда пишем статьи потом

- сколько стоит разработка сайта
- тильда или свой код что лучше
- чем плох сайт на конструкторе
- сколько стоит телеграм бот для бизнеса
- как выбрать разработчика сайта

### Просто изучает — на такие запросы бюджет не тратим

- что такое чат бот
- как работает нейросеть
- что такое вайбкодинг

## Мета-теги страницы

Title: Разработка сайтов и Telegram-ботов на заказ — от 15 000 ₽

Description: Заказать сайт, лендинг, чат-бота или ИИ-агента для бизнеса.
Пишем на чистом коде без конструкторов: сайт остаётся вашим, переделывать
не придётся. Срок от 3 дней, работаем по всей России.

Цена в заголовке отсекает тех, у кого бюджет три тысячи, ещё до клика.
В рекламе с оплатой за клики это экономит деньги напрямую.

## Для Яндекс.Директа

В Мастере кампаний вписать запросы из блока «Готов купить».
Обязательно добавить минус-слова, иначе бюджет уйдёт не туда:

```
-бесплатно -своими руками -самому -курсы -обучение -вакансия -работа
-скачать -шаблон -конструктор -урок -как сделать -пример -реферат
```

Без минус-слов половина кликов придёт от тех, кто хочет научиться делать
сайты сам, а не заказать.

## Чего на сайте не хватает под поиск

1. **Отдельных страниц под услуги.** Одна страница не может занять топ
   сразу по «заказать лендинг» и «разработка телеграм бота» — это разные
   запросы. Со временем стоит сделать `/landing`, `/telegram-bot`,
   `/ai-agent` с отдельными текстами.

2. **Статей.** Запросы из блока «сравнивает подрядчиков» — это готовые
   темы. «Тильда или свой код», «сколько стоит телеграм-бот» приводят
   людей, которые уже выбирают исполнителя.

3. **Города.** Если нужны заявки из КМВ, а не только по России, нужна
   страница вроде «разработка сайтов в Пятигорске». Локальные запросы
   заметно менее конкурентны.

Сейчас это отложено: сначала должна заработать реклама и появиться
первые заявки. SEO даёт результат через 2–6 месяцев, реклама — завтра.
