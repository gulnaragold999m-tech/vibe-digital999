# Прайс для карточки в Яндекс Картах — 60 позиций

## Зачем это

Яндекс сопоставляет карточку с запросом не только по названию и рубрике, но и по
названиям услуг в прайсе. Одна рубрика «Веб-студия» ловит один запрос. Шестьдесят
позиций ловят шестьдесят.

Поэтому названия здесь — не наши внутренние слова, а то, что человек набирает в поиске.
Основа — `docs/05-KEYWORDS.md`: там уже разобрано, что «вайбкодинг» почти никто не ищет,
а ищут «заказать лендинг» и «разработка телеграм бота».

Услуг за этими названиями по-прежнему шесть. Меняется формулировка, а не работа.

## Перед началом запишите цифры «до»

Иначе через месяц не с чем будет сравнить, и останется только ощущение «вроде лучше».

Яндекс Бизнес → Статистика. Выпишите за последние 30 дней:

| Показатель | Значение на \_\_\_\_\_\_ |
| --- | --- |
| Показы карточки в поиске и на карте |  |
| Переходы на сайт |  |
| Нажатия на телефон |  |
| Построения маршрута |  |
| Запросы, по которым нашли карточку (топ-10) |  |

Метрика → Источники → Переходы по рекламе, метка `geoadv` — это тот же трафик со стороны
сайта. На 6 августа там было 136 визитов за сутки.

Через месяц сверяем те же пять строк. Это и будет результат — с числами, а не словами.

## Куда это заводить

Яндекс Бизнес → ваша организация → **Товары и услуги** → добавить категорию → добавить
позицию. Три поля: название, цена, описание. Картинка не обязательна, но с ней позицию
открывают чаще.

Заводите по одной категории за раз. Шестьдесят позиций за один присест не осилить, а
брошенный на середине прайс выглядит хуже, чем короткий, но законченный.

## Чего не делать

**Не ставить логотипы и надписи на фотографии.** Модерация Яндекса снимает снимки с
рекламными наложениями. Фото должно показывать работу, а не быть баннером.

**Не тратить время на геометки в файлах фотографий.** EXIF-координаты снимка на
ранжирование карточки не влияют — это популярный пункт в чужих отчётах, который ничего
не меняет.

**Не дублировать названия.** Шестьдесят позиций с одинаковым смыслом и разными словами —
это нормально, а вот две позиции с одним названием Яндекс склеит.

## Что даст больше всего

По убыванию отдачи:

1. **Прайс** — то, что выше. Больше всего новых запросов.
2. **Отзывы и ответы на них.** Не только ответить на старые, но наладить поток новых.
   Свежесть отзывов Яндекс учитывает.
3. **Заполненность профиля** — рубрики, часы, атрибуты, описание.
4. **Фотографии** — влияют через поведение: карточку с нормальными фото открывают чаще.
5. **Публикации и сторис** — визуал, на видимость влияют слабо.

Через месяц возвращаемся к таблице «до» в начале файла и сверяем.
