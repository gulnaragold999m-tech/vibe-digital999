# 04 — Публикация сайта на Amvera

## Сначала — обязательный шаг по безопасности

В старом сайте токен Telegram-бота был вписан прямо в код страницы. Такой код видит любой
посетитель через «Просмотр исходного кода». Значит, токен нужно считать украденным.

1. Откройте в Telegram чат с `@BotFather`.
2. Команда `/mybots` → выберите бота → `API Token` → `Revoke current token`.
3. BotFather выдаст новый токен. Старый перестанет работать у всех, включая злоумышленников.
4. Новый токен впишите в файл `.env` и в переменные окружения Amvera. Больше никуда.

В новом коде токен лежит только на сервере. В браузер он не попадает.

## Шаг 1. Создайте файл .env

Скопируйте `.env.example` в `.env` и заполните:

```
BOT_TOKEN=новый_токен_от_BotFather
CHAT_ID=ваш_числовой_id_в_телеграм
PORT=3000
```

Узнать свой `CHAT_ID`: напишите боту `@userinfobot`, он пришлёт номер.

## Шаг 2. Проверьте сайт у себя на компьютере

```bash
npm install
```

```bash
npm start
```

Откройте `http://localhost:3000`, заполните форму и убедитесь, что заявка пришла в Telegram.

## Шаг 3. Создайте проект на Amvera

1. Зайдите на amvera.ru, нажмите «Создать проект».
2. Тип окружения: **Node**, не «статический сайт». Статика не подойдёт: сайту нужен сервер,
   который принимает заявки и хранит токен.
3. Тариф — минимальный.

Файл `amvera.yaml` уже лежит в корне проекта, Amvera прочитает его сам:

```yaml
meta:
  environment: node
  toolchain:
    name: npm
    version: 20

run:
  command: npm start
  containerPort: 3000
  persistenceMount: /data
```

Отличия от проекта `granat_site`, где стоит Python: там `environment: python`,
`toolchain: pip` и запуск через `gunicorn` на порту 80. Структура файла та же самая —
`meta`, `build`, `run`, — меняется только начинка под язык.

Секция `build` нам не нужна: Amvera сама ставит зависимости по `package.json`.
Она понадобилась бы только для сборки фронтенда, а у нас чистый HTML.

## Шаг 4. Загрузите код

Через Git (удобнее для обновлений) или ZIP-архивом.

Если архивом: выделите `public`, `api`, `server.js`, `package.json`, `package-lock.json`,
`amvera.yml` и запакуйте. **Файл `.env` и папку `node_modules` в архив не кладите.**

## Шаг 5. Переменные окружения на Amvera

Проект → Настройки → Переменные окружения. Добавьте:

| Имя | Значение |
|-----|----------|
| `BOT_TOKEN` | новый токен от BotFather |
| `CHAT_ID` | ваш ID в Telegram |

Без них форма ответит «Сервис приёма заявок не настроен».

## Шаг 6. Домен

Домен `vibe-digital999.ru` зарегистрирован в **reg.ru** (NS-серверы `ns1.reg.ru`, `ns2.reg.ru`).

Порядок обратный тому, что кажется логичным: **сначала записи у регистратора, потом кнопка
в Amvera**. Amvera проверяет TXT-запись при нажатии «Применить» и отказывает, если её нет.

### Что прописать в reg.ru

Личный кабинет reg.ru → Мои домены → `vibe-digital999.ru` → Управление зоной DNS.

| Тип | Хост | Значение |
|-----|------|----------|
| A | `@` | `158.160.116.199` |
| TXT | `@` | `granatgold999-vibe-digital` |

Старую A-запись `95.163.244.138` нужно **удалить** — это парковочная страница reg.ru.
Amvera требует, чтобы A-запись была ровно одна.

Проверьте также, что нет записей AAAA и не подключён Cloudflare, а SSL у регистратора
выключен: сертификат выпускает Amvera сама при привязке домена.

### Дальше

1. Подождать, пока записи разойдутся по интернету: обычно 15–60 минут, иногда до 12 часов.
2. Проверить командой ниже — она должна показать `158.160.116.199`.
3. Вернуться в Amvera → Домены → добавить `vibe-digital999.ru` → Применить.
4. SSL Amvera выпустит автоматически.

Проверка записей без ожидания вслепую:

```bash
curl -s "https://dns.google/resolve?name=vibe-digital999.ru&type=A" | grep -o '"data":"[^"]*"'
```

```bash
curl -s "https://dns.google/resolve?name=vibe-digital999.ru&type=TXT" | grep -o '"data":"[^"]*"'
```

## Шаг 7. Яндекс.Метрика

Счётчик **110416869** уже вписан в код. Осталось два действия в кабинете Метрики.

1. Настройки счётчика → поле «Адрес сайта»: поменяйте `my-vibecoding-agenci.vercel.app`
   на `vibe-digital999.ru`, а старый адрес добавьте в «Дополнительные адреса»
   (или удалите, если Vercel-версия больше не нужна). Без этого часть визитов
   может отсеиваться как чужой домен.
2. Настройки → Цели → Добавить цель → тип **JavaScript-событие**.

Учтите: счётчик уже собирал данные по старому сайту, где форма была сломана. Старая статистика
перемешается с новой. Если хотите чистые цифры для обучения Директа — заведите новый счётчик
и замените номер в строке `const YM_ID = ...` в `public/index.html`.

Идентификаторы целей, которые уже вшиты в код:

| Идентификатор | Когда срабатывает |
|---------------|-------------------|
| `click_wa` | клик по WhatsApp |
| `click_tg` | клик по Telegram |
| `click_vk` | клик по ВКонтакте |
| `open_chat_max` | открытие чата с ассистентом |
| `click_order` | клик по кнопке «Заказать» |
| `lead_sent` | заявка успешно отправлена |

## Шаг 8. Яндекс.Директ без слива бюджета

1. Директ → Добавить кампанию → **Мастер кампаний**.
2. Ссылка — на новый сайт.
3. География: вся Россия либо Москва, Санкт-Петербург, Краснодарский край, Ростовская область.
   Привязку только к КМВ снимите: автоматизация продаётся удалённо.
4. Стратегия: **оплата за конверсии**, не за клики.
5. Целевое действие: `lead_sent` или `click_wa`.
6. Цена конверсии: 300–600 ₽.
7. Недельный бюджет: например, 5 000 ₽. Больше этой суммы Директ списать не сможет,
   а без заявок деньги вообще не спишутся.

## Если что-то сломалось

Логи проекта на Amvera покажут ошибку. Скопируйте текст ошибки — разберём.
Проверить, жив ли сервер: откройте `ваш-домен/health`, там должно быть `{"ok":true}`.
