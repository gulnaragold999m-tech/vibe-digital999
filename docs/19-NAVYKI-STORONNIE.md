# Чужие навыки: 3D, анимации, дизайн-система

Как поставить готовые навыки из интернета — three.js, GSAP, дизайн —
и чем они отличаются от MCP. Проверено 13.08.2026: все команды в этом
файле выполнены и дали результат, а не переписаны из пересказа.

---

## 1. Навык — это НЕ MCP. Главная путаница

Пересказ, с которого начали, утверждал: «обычно такие кастомные навыки
для Claude реализуются через протокол MCP», и предлагал искать файл
`claude_config.json`. **Это неверно, и по этому пути ничего не заработает.**

| | Навык (Skill) | MCP |
|---|---|---|
| Что это | папка с файлом `SKILL.md` — текст, знание | внешняя программа-сервер |
| Что даёт | агент знает, КАК делать | агент получает новый инструмент |
| Как ставится | скопировать папку | прописать запуск сервера |
| Настройка | никакой | `.mcp.json` или `claude mcp add` |

Файла `claude_config.json` в Claude Code нет вовсе. Навык подхватывается
сам, как только его папка лежит в нужном месте.

Куда класть — два места, и разница важная:

| Куда | Путь на Windows | Кто видит |
|---|---|---|
| Глобально | `C:\Users\<имя>\.claude\skills\` | все проекты на этом компьютере |
| В проект | `<папка проекта>\.claude\skills\` | этот репозиторий, у всех, кто его склонирует |

**Ловушка:** глобальные навыки лежат на компьютере Гульнары и в git
не попадают. Чат, открытый в браузере (claude.ai/code), работает
на чужой машине и их **не видит**. Нужно, чтобы навык был доступен
и там, — ставить его в проект, а не глобально.

## 2. Пять навыков, все проверены

Источник — публикация `dashi_agent`, семь слайдов. Названия и авторство
сверены по GitHub, каждый репозиторий открыт руками.

| Навык | Репозиторий | Что внутри | Звёзд |
|---|---|---|---|
| Three.js | `CloudAI-X/threejs-skills` | 10 навыков: сцена, геометрия, материалы, свет, текстуры, анимация, загрузка моделей, шейдеры, постобработка, взаимодействие | ~3 000 |
| GSAP | `greensock/gsap-skills` | 8 навыков: ядро, таймлайны, ScrollTrigger, плагины, React, утилиты, производительность. **Официальный, от самих GreenSock** | — |
| Design DNA | `zanwei/design-dna` | разбирает чужой сайт или скриншот на палитру, отступы, шрифты и эффекты, потом собирает по этой «ДНК» свой | ~1 400 |
| Motion Design | `LottieFiles/motion-design-skill` | принципы движения: тайминг, плавность, очерёдность появления, законы диснеевской анимации на язык интерфейса. Не про библиотеку, а про вкус — ложится поверх GSAP, CSS или Lottie | ~967 |
| Genjutsu | `AThevon/genjutsu` | движение и интерактив: анимации, 3D, дизайн-системы | ~216 |

**Пятый навык чуть не потеряли.** До меня дошёл пересказ этой же
публикации, и в нём Motion Design не было вовсе — четыре вместо пяти.
Имена и авторство на этот раз не переврались, а целый пункт выпал.
Ровно тот случай, ради которого записано правило: **просить
первоисточник, даже когда пересказ выглядит аккуратным.** Нашёлся он
только когда владелица прислала сами скриншоты.

**GSAP с 2025 года бесплатен целиком**, включая платные раньше плагины
SplitText и MorphSVG, — после покупки Webflow. Клубного членства
и токена в `.npmrc` больше не нужно, всё ставится из обычного
пакета `gsap`.

**Motion Design и Genjutsu — про одно и то же, но с разных сторон.**
Первый даёт правила («сколько миллисекунд, какая кривая, что появляется
первым»), второй — вкус и общее направление. Ставить можно оба,
но если выбирать один, начинать с Motion Design: он у известного
автора и в десять раз популярнее.

## 3. Установка — одна команда на каждый навык

Выполняется в чёрном окне, в любой папке. `-g` означает «глобально,
для всех проектов»:

```
npx skills add CloudAI-X/threejs-skills -a claude-code -g -y
```

```
npx skills add greensock/gsap-skills -a claude-code -g -y
```

```
npx skills add zanwei/design-dna -a claude-code -g -y
```

```
npx skills add LottieFiles/motion-design-skill -a claude-code -g -y
```

Проверено 13.08.2026 — все четыре отработали, положили 20 папок
в `~/.claude/skills/`. Что должно быть на экране: рамка со списком
и галочками `✓ gsap-core (copied)`, в конце `Done!`.

**Без `-g`** та же команда кладёт навык в `.claude\skills\` текущего
проекта — и тогда он уезжает в git вместе с репозиторием. Так ставим,
если навык нужен на клиентском сайте и облачным чатам.

Genjutsu ставится иначе — он не только навык, но и набор команд.
Внутри Claude Code набрать две строки подряд:

```
/plugin marketplace add AThevon/genjutsu
```

```
/plugin install genjutsu
```

GSAP тоже умеет так (`/plugin marketplace add greensock/gsap-skills`),
у него в репозитории лежит `.claude-plugin/marketplace.json`.

Проверить, что встало: в Claude Code команда `/plugins`, либо
посмотреть глазами папку `C:\Users\<имя>\.claude\skills`.

## 4. Три ловушки, на которые уже наступили

**Инструкция в README у `threejs-skills` — нерабочая.** Она предлагает
`git clone https://github.com/pinkforest/threejs-playground.git` — такого
репозитория не существует, адрес отдаёт 404. И папку называет
`.claude/skills`, хотя в самом репозитории навыки лежат в `skills/`.
Ошибка не в пересказе, а в первоисточнике: **README тоже проверяют.**

**Через `/plugin marketplace add` ставятся не все.** Папка
`.claude-plugin/` есть только у GSAP и у Genjutsu. У `threejs-skills`,
`design-dna` и `motion-design-skill` её нет — для них
`/plugin marketplace add` не сработает, только `npx skills add`
или копирование папок руками. Поэтому в разделе 3 у всех одна
команда: она работает везде, а `/plugin` — через раз.

**Навык исполняется с полными правами агента.** Это инструкции, которые
чат выполнит не задумываясь. Сам установщик пишет об этом в конце:
«Review skills before use; they run with full agent permissions».
Ставим только то, у чего видно автора: GSAP официальный от GreenSock,
у остальных смотрим звёзды и открываем `SKILL.md` глазами.

## 5. Что это значит для наших сайтов

Навык — это знание, а не библиотека: сам по себе он ничего на сайт
не добавляет и ничего не весит. Вес появится, когда мы по его совету
подключим GSAP и Three.js в страницу.

**На наш сайт `vibe-digital999.ru` их не тащить без причины.**
Правило стека в `CLAUDE.md` — vanilla JS, фон уже нарисован на Canvas
своими силами. Three.js — это сотни килобайт, и он тянется до первой
отрисовки. Мы продаём быстрые сайты и меряем скорость прямо на главной;
проиграть собственному тест-драйву — дорогая покупка за красивую сцену.

**Где это уместно.** Клиентский премиум-лендинг, где 3D и есть продукт:
интерьеры, мебель, украшения, автомобили. Там сцена окупает вес.
И тогда — сразу с оглядкой на телефон и на `prefers-reduced-motion`:
у GSAP для этого есть `gsap.matchMedia()`, и навык `gsap-core` его
показывает.
